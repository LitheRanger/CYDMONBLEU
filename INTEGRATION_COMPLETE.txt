📊 BASE DE DATOS
════════════════════════════════════════════════════════════════════════════════

Tabla: returns_requests
├─ id (INT, PRIMARY KEY)
├─ order_id (VARCHAR) .................... De Shopify
├─ contact_email (VARCHAR) ............... Cliente
├─ return_type (VARCHAR) ................. 'exchange' o 'return'
├─ items_json (JSON) ..................... Array de productos
├─ files_json (JSON) ..................... Imágenes subidas
├─ amount (DECIMAL) ...................... Monto a pagar
├─ payment_status (VARCHAR) .............. 'pending', 'paid', 'failed'
├─ stripe_session_id (VARCHAR) ........... ID sesión Stripe
├─ carrier (VARCHAR) ..................... 'FEDEX'
├─ tracking_number (VARCHAR) ............. Número de seguimiento
├─ label_base64 (MEDIUMTEXT) ............. PDF etiqueta en base64
├─ label_mime (VARCHAR) .................. 'application/pdf'
├─ label_created_at (TIMESTAMP) .......... Cuándo se generó etiqueta
└─ created_at (TIMESTAMP) ................ Cuándo se creó


📡 ENDPOINTS DISPONIBLES
════════════════════════════════════════════════════════════════════════════════

GET /api/admin/requests
    ↳ Listar todas las solicitudes
    ↳ Requiere: Basic Auth

GET /api/admin/requests/:id
    ↳ Obtener detalles de una solicitud
    ↳ Requiere: Basic Auth

GET /api/label/:requestId
    ↳ Descargar etiqueta FedEx en PDF
    ↳ Base64 → Descarga automática

POST /api/admin/requests/:id/retry-label
    ↳ Regenerar etiqueta FedEx
    ↳ Requiere: Basic Auth

   ├─ Clic en "Pagar"

3. SISTEMA PROCESA PAGO
   ├─ Webhook valida firma
   ├─ Actualiza BD: payment_status='paid'
   ├─ Obtiene orden de Shopify
   ├─ Genera etiqueta FedEx
   ├─ Guarda tracking en BD
   └─ Registra evento en historial

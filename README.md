# CYDMONBLEU

Sistema de gestión de devoluciones para MON|BLEU.

## Despliegue en Render

Para instrucciones completas de despliegue en Render, consulta [DEPLOYMENT_RENDER.md](./DEPLOYMENT_RENDER.md).

### Variables de Entorno Principales

- `DISABLE_DB`: Activar modo sin base de datos local (para Render)
- `GESTOR_API_URL`: URL del backend GESTORCYDMONBLEU
- `ADMIN_USER` / `ADMIN_PASS`: Credenciales para panel admin
- `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET`: Configuración de Stripe
- Consulta [DEPLOYMENT_RENDER.md](./DEPLOYMENT_RENDER.md) para la lista completa
